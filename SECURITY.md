# Security Policy

The MyMeto Weather team takes security vulnerabilities seriously. We appreciate your efforts to responsibly disclose your findings, and we will make every effort to address them in a timely manner.

## Supported Versions

Please note that security updates will typically be applied to the latest version of our application. We encourage all users to stay updated to ensure they have the latest security patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

*(Please adjust the version numbers and support status as applicable to your project.)*

## Reporting a Vulnerability

If you discover a security vulnerability, please report it to us as soon as possible. We prefer that you contact us privately to prevent public disclosure of the vulnerability before it can be addressed.

Please send an email to **`[CONTACT_EMAIL_OR_LINK_TO_SECURITY_REPORTING_FORM]`** with the details of the vulnerability.

When reporting, please include the following information if possible:

*   A clear description of the vulnerability.
*   Steps to reproduce the vulnerability.
*   The potential impact of the vulnerability.
*   Any suggested mitigations or fixes, if you have them.

We will acknowledge receipt of your vulnerability report within 48 hours and will strive to provide an estimated timeframe for addressing the vulnerability.

## Disclosure Policy

Our goal is to address security vulnerabilities in a timely manner. Once a vulnerability is confirmed and a fix is developed, we will:

1.  Release a patch or updated version of the application.
2.  Notify the reporter that the vulnerability has been addressed.
3.  (Optional, if applicable) Publicly acknowledge the reporter for their contribution, if they agree.

We request that you do not publicly disclose the vulnerability until we have had a reasonable amount of time to address it. We aim to coordinate public disclosure with the release of a fix.

## Scope

This security policy applies to the MyMeto Weather application and its associated backend services. If you are unsure whether a vulnerability is in scope, please contact us at the email address provided above.

We value the work of security researchers and the community in helping us maintain a secure application. Thank you for your contributions.
